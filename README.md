# Conecta Comedor

El proyecto "ConectaComedor" consiste en el desarrollo e implantación de una plataforma web
responsive y una aplicación móvil cuyo objetivo principal es centralizar y dinamizar el acceso a
los servicios de los comedores sociales.

Más allá de ser un simple directorio "ConectaComedor" se concibe como un ecosistema digital que conecta a las personas en situación de vulnerabilidad alimentaria con los recursos disponibles, al mismo tiempo que dota a los comedores de herramientas para optimizar su gestión diaria, mejorar la comunicación y fomentar la transparencia y las donaciones.
